# Custom Label by VOLTFUSE - Website

The new marketing site for Custom Label, the custom-headwear partner brand by VOLTFUSE.

- `site/` - the deployable static site (no build step). See `site/README.md` for details.
- `site-src/` - shared header/footer partials and `build.sh` to regenerate the assembled pages.
- Live preview: deployed to GitHub Pages from `site/` on every push to `main`.
